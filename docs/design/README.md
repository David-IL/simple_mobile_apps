# Design

Wireframes live here as `<app-slug>.excalidraw`, edited with the **Excalidraw VS Code
extension** (`pomdtr.excalidraw-editor`) — no external tool or account, and the files are
version-controlled alongside the code.

Suggested per app: one file with a frame per screen, plus arrows for navigation flow.
Rough boxes are enough — the goal is deciding what's on each screen, not pixel polish.

See [ADR 0005](../adr/0005-component-preview-approach.md) for why there's no Storybook yet.
